# Redis Practice

यह प्रोजेक्ट Redis के साथ Node.js backend और React frontend का एक सरल full-stack practice ऐप है।

## प्रोजेक्ट की संरचना

- Backend: Node.js/Express सर्वर, जिसमें Redis integration शामिल है
- Frontend: React + Vite client

## Git ignore

रूट लेवल पर एक ignore file शामिल है, ताकि dependencies, environment files, logs और build artifacts को version control में शामिल न किया जाए।

## चलाने के लिए

1. Backend को चलाने के लिए संबंधित folder में依存साइट install करें
2. Frontend को चलाने के लिए client folder में依存साइट install करें
3. दोनों services को अलग-अलग запуск करें
